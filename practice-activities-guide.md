Practice Activities Guide

Description: This Practice Activities Guide is a helper guide for AI agent to effectively create real-world activities to help learner apply effective theories and syntaxes requriement to master Data Engineer / Analytics using SQL and Python.

#Folder 1: /practice-activities
    - Where the activity will be placed
    - Naming system: act[unit number-number]-[difficulty]-[topic]
#Folder 2: /practice-activities-solution
    - Where the cheat solution will be placed
    - Naming system: sol[unit number-number]-[difficulty]-[topic]
#Folder 3: /practice-activities-sql
    - dataset[unit number-number]-[difficulty]-[topic].sql
    - Python script seeding

**Objective**
    a. Apply all of the mentioned syntaxes, and theories in solving relevant real-world problems
    b. Learner can demonstrate mastery of syntaxes in both language
    c. Understand how data cleaning, maintaing, securing, and modifying 
    d. Learner can showcase the activity to the interview
    c. Demonstare problem solving skills
   

**Rule**
1. Focus only in the lesson provided. No introducing concept or syntax, but expect the learner to have at least surface knowledge of both SQL and Python Libraries.
2. Unit one activities must only have Unit one.
3. Unit two activities can have Unit one Lesson dipending on the problem, same goes to Unit Three can both have the previous Units - This is only applied on hard difficulty.
4. ensure a progressive activities.
5. Have difficulty level easy, medium, hard
6. Format:
   both activity and solution is .md file
   a. Activity should have the problem scenario (e.g, An e-commerce business stores customer demographics in a customers table and transactional logs in an orders table [cite: 1, 15]. The analytics team must generate a unified customer report. This report must compute the total and average order amounts for each customer segment, ensuring that inactive customers are preserved in the final output [cite: 1, 10].) with "HINTS" in sentence format to give the learner a room for thinking
   b. cheat solutions should be in syntax form with reason why — in comment type both python version and sql version.
   c. dataset sql maximum of 200 data.
7. Some problems can be connected to one another creating a chain of progression in a unit, for example: activity 1 -> activity 2.

Note: the agent is allowed to create python scripting to seed the sql file(s).
Note: dataset can be the same to other problems but the problem itself must be different.
Note lesson is already been provide at lessons\Relational-Programmatic.md
